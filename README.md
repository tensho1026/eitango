# eitango

Next.jsで作った、ターゲット1900（6訂版）のシンプルな英単語アプリ。1900語は `src/data/target1900.json` に同梱し、ローカルファイルから読み込みます。起動・ビルドにDBや接続用の環境変数は不要です。

- 1〜200、201〜400、…、1601〜1800、1801〜1900の10区分から選択。
- ボタン1つで「意味を見る → 次の単語へ」を繰り返す。
- 範囲の最後に完了画面を表示し、同じボタンで再学習。
- スマホではコンパクトな範囲選択と大きな学習ボタン。
- iPadの縦向き・Split Viewでは、範囲選択を上にまとめた広い単語カード。
- iPadの横向き・デスクトップでは2列の配置。
- スマホの横向きでは範囲選択を左に寄せ、カードをコンパクトに表示。

長い英単語はカードの幅と文字数に応じて文字を縮め、日本語の意味は折り返して表示します。小さな画面では補足説明を省き、選択欄の文字は16px以上にしています。スマホの学習ボタンは縦向き56px以上、横向き52px以上の高さです。

画面例: [スマホ](docs/preview-phone.jpg) / [iPad](docs/preview-ipad.jpg) / [PC](docs/preview.jpg)

学習中の位置は画面を開いている間だけ保持します。再読み込み時は選択した範囲の最初に戻ります。

## 起動

Node.js 22以上を使います。

```sh
npm ci
npm run dev
```

[http://localhost:3000](http://localhost:3000)を開きます。

## 単語ファイル

`src/data/target1900.json` に出典・版・各単語のID、掲載番号、英単語、日本語の意味、追加フラグを保存しています。最初から1900語を同梱しているため、取得スクリプトの実行は不要です。

Server ComponentでローカルJSONから選択した100〜200語だけを読み出し、学習画面に渡します。画面表示時に外部サービスに接続する処理はありません。

取得元: [受かる英語の単語一覧](https://ukaru-eigo.com/target-1900-word-list/)

元ページから単語ファイルを更新する場合のみ、次のコマンドを使います。

```sh
npm run import:words -- --dry-run
npm run import:words
```

1900件、掲載番号の欠落・重複・空欄を確認し、一時ファイルから置き換えます。不完全な取得結果で既存ファイルを上書きしません。既存のIDと意味の注釈を保持します。実行後はアプリを再ビルドします。

## 検証・本番起動

```sh
npm run lint
npm run typecheck
npm test
npm run build
npm start
```

テストは同梱データの1900件と各区分の読み込み、ボタンの状態遷移、HTML抽出の異常検出、ローカルファイル更新時のID維持と不正データの拒否を検証します。

`.env`で始まるファイルはすべてGitの対象から除外しています。GitHubへ送る前に`npm run check:secrets`でGitの登録ファイルを確認できます。

技術構成: Next.js App Router、React、TypeScript、CSS、ローカルJSON。
