# eitango

Next.jsで作った、ターゲット1900（6訂版）のシンプルな英単語アプリ。1900語は `src/data/target1900.json` に同梱し、ローカルファイルから読み込みます。苦手単語の登録だけをNeon Postgresに保存します。

- ホームで1〜200、201〜400、…、1601〜1800、1801〜1900の10区分から選択。
- ホームで「通常」「自動（2秒）」「自動（3秒）」の学習モードを選択。
- 学習方法を「英語→日本語」「日本語→英語」「スペル入力テスト」から選択。スペル入力は通常モードで答え合わせをして進む。
- シャッフルを有効にすると、選んだ範囲・苦手単語を重複なく並べ替える。
- 範囲を選ぶと専用の学習ページ `/study?start=...` に移動。
- 学習画面には英単語・赤文字の意味・左上のホームへの左矢印・右上の苦手登録用の星を表示。意味は項目ごとに改行し、括弧内の注釈はまとめて表示。
- 通常モードは学習ボタン1つで「意味を見る → 次の単語へ」を繰り返す。
- 自動モードでは単語と意味を最初から表示し、選択した2秒または3秒間隔で次へ進む。範囲の最後で停止する。
- 範囲の最後に「完了」を表示し、「もう一度学習する」で同じモードを再学習。
- 星を押すと苦手単語に登録し、もう一度押すと解除。保存に成功したら星の色が変わる。
- ホームの「苦手単語だけ復習」から、範囲をまたいで登録した単語だけを掲載順に復習できる。通常・自動（2秒）・自動（3秒）の全モードに対応。
- 苦手復習は「すべて」または200語ごとの範囲で絞り込める。最後の範囲は1801〜1900番。
- 苦手単語の一覧で単語・意味を確認し、その場で登録を解除できる。一覧から選択範囲の復習を開始できる。
- 復習中の「覚えた」で苦手登録を解除し、次の単語に進む。DB保存に失敗した場合は同じ単語にとどまる。
- 単語・意味の部分を左にスワイプすると次、右にスワイプすると前へ。縦スクロールや入力欄の操作では移動しない。

長い英単語は画面幅と文字数に応じて文字を縮め、日本語の意味は折り返して表示します。スマホ・iPadに対応し、学習ボタンは56px以上の高さです。スマホの横向きでは単語と操作ボタンを左右に並べます。

学習位置・表示状態・入力内容・シャッフルした順番は、同じブラウザのlocalStorageに保存します。ホームの「続きから再開」や同じ範囲・設定を選ぶと再開できます。保存は範囲・学習方法・速度・出題順ごとに分け、最近の30セッションを保持します。完了するとその再開位置を削除し、「もう一度学習する」では最初から始めます。シャッフルの再学習時は改めて並べ替えます。

途中でも最初から始めたい場合は、ホームの「再開位置をリセット」で表示中の履歴を削除してから範囲を選びます。苦手登録は保持されます。

復習を再開するときは卒業・解除した単語を除き、新しく登録された単語を反映します。自動学習はページを離れている間は止まり、戻った単語から選択した秒数で再開します。ブラウザの保存データを削除すると再開位置も消えます。

## 起動

Node.js 22以上を使います。

苦手登録には、Gitの対象から除外されている `.env.local` にNeonの接続文字列を設定します。実際の認証情報はGitHubに保存しません。

```dotenv
DATABASE_URL=postgresql://USER:PASSWORD@HOST/DATABASE?sslmode=require
```

必要に応じてマイグレーション用の直接接続URLを `DATABASE_URL_UNPOOLED` に設定できます。未指定時は接続先の `-pooler` を除いた直接接続を使います。

```sh
npm ci
npm run db:migrate
npm run dev
```

[http://localhost:3000](http://localhost:3000)を開きます。

## 単語ファイル

`src/data/target1900.json` に出典・版・各単語のID、掲載番号、英単語、日本語の意味、追加フラグを保存しています。最初から1900語を同梱しているため、取得スクリプトの実行は不要です。

通常の範囲学習ではServer ComponentでローカルJSONから選択した100〜200語だけを読み出し、学習画面に渡します。苦手復習では同じローカルデータから登録番号に一致する単語を抽出します。

取得元: [受かる英語の単語一覧](https://ukaru-eigo.com/target-1900-word-list/)

元ページから単語ファイルを更新する場合のみ、次のコマンドを使います。

```sh
npm run import:words -- --dry-run
npm run import:words
```

1900件、掲載番号の欠落・重複・空欄を確認し、一時ファイルから置き換えます。不完全な取得結果で既存ファイルを上書きしません。既存のIDと意味の注釈を保持します。実行後はアプリを再ビルドします。

## 苦手登録の保存

`difficult_words` テーブルにブラウザごとの利用者ID・掲載番号・登録日時を保存します。利用者IDはサーバーで作成し、HttpOnly Cookieで保持します。同じブラウザでページを閉じても登録は残ります。ログイン機能はなく、別のブラウザや端末では別の登録になります。Cookieを削除すると以前の登録にはアクセスできなくなります。

登録・解除・卒業は `/api/difficult` が入力を検証して処理し、他の利用者の登録には影響しません。複合主キーで同じ単語の重複登録を防ぎます。星で登録を解除した場合は現在の単語を飛ばさず、「覚えた」では保存成功後に次へ進みます。次の復習開始時には最新の登録を反映します。

スキーマは `db/difficult-schema.ts`、マイグレーションは `drizzle-difficult/` にあります。変更時は `npm run db:generate` でSQLを生成し、確認してから `npm run db:migrate` を実行します。マイグレーション履歴には専用の `drizzle.eitango_difficult_migrations` を使い、既存の単語テーブルや旧マイグレーション履歴を変更しません。

## 検証・本番起動

```sh
npm run lint
npm run typecheck
npm test
npm run build
npm start
```

テストは同梱データの1900件と各区分の読み込み、通常・自動モードの状態遷移と完了後の停止、HTML抽出の異常検出、ローカルファイル更新時のID維持と不正データの拒否を検証します。苦手登録はPGliteのPostgresエンジンでマイグレーションの再実行、重複防止、利用者ごとの読み込み・解除を検証します。テストにNeonの認証情報は不要です。

学習設定のURL、保存の復元と破損データの拒否、シャッフルの重複・欠落、卒業後の再開、範囲の境界、スワイプの方向と端の扱い、スペル判定も検証します。

`.env`で始まるファイルはすべてGitの対象から除外しています。GitHubへ送る前に`npm run check:secrets`でGitの登録ファイルを確認できます。

技術構成: Next.js App Router、React、TypeScript、CSS、ローカルJSON、Drizzle ORM、Neon Postgres。
